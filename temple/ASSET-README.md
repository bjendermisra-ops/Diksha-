# ISKCON Hadapsar — independent photographic website assets

This repository now contains actual optimized WebP images in `temple/assets/`, not remote-linked placeholder images. Sources are publicly displayed temple website media and the existing repository's visual material. We own the deployed file copies in GitHub and no longer depend on the former Hostinger media server for the new pages.

## Asset inventory
- Desktop and mobile photographic hero compositions, plus deity and temple-related image crops.
- Five program banners: Bhagavat Katha, Gita Mahayagna, Drawing Competition, Dindi, Prabhupada Prasad.
- Three festival images: Janmashtami, Rath Yatra and Kartik.
- Portrait, devotees and supporting images.
- Local official-site logo asset and existing decorative SVG files: lotus, peacock feather, gold dividers, icons and textures.

Images were sourced from the public ISKCON Hadapsar website and local project artwork. Some source images are photographs; some are devotional paintings/illustrations. **The hero background is an editorial composite, not a verified exterior photograph of the Hadapsar temple.** The dates on past competition pages are preserved as archive items, not active registration.

## Visual system
`temple/atelier.css` controls the editorial typography, five-program collection, photo-driven festivals, hero and mobile treatment. `temple/temple.js` implements accessible navigation and viewport-aware reveals, disabled by `prefers-reduced-motion`.

The original Diksha invitation at `/` and its admin panel at `/admin` remain unchanged.
